## 토의할 내용

- [ ] 전체 무드 (A / B / C / 혼합)
- [ ] 메인 컬러
- [ ] 국문 / 영문 타이틀 비중
- [ ] 필수 정보: 일시, 장소, 지도, 연락처, 계좌번호 여부
- [ ] 종이 청첩장 / 모바일 청첩장 / 둘 다

## 의견 남기는 방법

1. 상단 **Issues** 탭 → **New issue**
2. **디자인 피드백** 템플릿 선택
3. 선호 시안과 이유를 적어 제출

## 폴더 구조

```
wedding-invitation/
├── index.html          # 시안 비교 페이지 (GitHub Pages)
├── README.md
├── designs/            # 시안 이미지
└── .github/ISSUE_TEMPLATE/design-feedback.md
```

새 시안을 추가할 때는 `designs/` 에 `draft-d-설명.webp` 처럼 넣고, 이 README 표와 `index.html` 에 카드를 하나 추가하면 됩니다.
